# Curriculum authoring

The single route manifest is `site/curriculum.json`. All routes, counts, and lesson outlines on the site come from it. This is a proposed map, not a claim of exhaustive coverage. One sample lesson is available; remaining lessons are planned.

Each authored lesson should include: a motivating question, prerequisites, intuition, a small runnable experiment, expected output, one variation to try, a understanding check, and primary-source references. Store narrative and runnable Python together in `lessons/<slug>/`. Review numerical behavior and API versions before changing a lesson to published.

Shared-conversation content is pending. Reconcile it against this map before expanding the curriculum.
