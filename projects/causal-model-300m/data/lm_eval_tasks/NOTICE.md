# Native task definitions

The HellaSwag preprocessing helper and HellaSwag/ARC-Easy task definitions
derive from EleutherAI's lm-evaluation-harness, task-source revision
`ddd67220430a2470529f25fd5c05a576ca1057a0`.
The local YAML files pin dataset revisions for this custom eight-record smoke
protocol. The installed execution distribution is separately pinned to 0.4.13.
Retain the accompanying EleutherAI MIT license with these files.

Task datasets retain their own provenance and terms. These source files do not
contain their downloaded records or pretrained model weights.
