# Data provenance and rights

This package was trained in part on the official [AllenAI SciFact release](https://github.com/allenai/scifact). The exact source archive SHA-256 is `11c621288d41ac144d29b13b0f8503b3820b7d6e8b1f6ff24dff335c196d76be`. The upstream [SciFact license terms](https://raw.githubusercontent.com/allenai/scifact/master/LICENSE.md) separate CC BY 4.0 claims/evidence annotations from the scientific abstract corpus sourced from S2ORC under ODC-By 1.0; the original code is Apache-2.0. See the [SciFact data schema](https://raw.githubusercontent.com/allenai/scifact/master/doc/data.md) and [paper](https://arxiv.org/abs/2004.14974). Evidence document IDs, not cited-document metadata, supply retrieval positives.

The C01 package does not assert a standalone license for trained model weights. Source-data permissions and attribution implications must be reviewed before redistribution. Full source member hashes, pinned upstream revision, split inventories, and normalized output hashes are recorded in the external source-bound receipt and frozen project recipe. The pinned MiniLM baseline is a separate Apache-2.0-reported model with possible S2ORC/MS MARCO overlap; it is not bundled into this package.
