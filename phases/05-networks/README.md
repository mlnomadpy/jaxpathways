# Phase 05: Neural network training

Training systems.

**Prerequisites:** 04: Math & optimization.

**Hardware:** CPU first; accelerator for larger experiments.

## Lesson sequence

### 05.01 Build a tiny multilayer perceptron

Status: planned brief.

**Learn and build:** Implement a small model with explicit parameters before adding a model library.

**Evidence:** A reproducible experiment for “Build a tiny multilayer perceptron”: code, environment, observed output, and an explanation of one deliberate change.

**Checkpoint:** Explain your result for “Build a tiny multilayer perceptron”, identify one failure case, and show how you verified the fix.
