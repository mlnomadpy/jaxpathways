# Phase 04: Math & optimization

Shared foundations.

**Prerequisites:** 03: State, randomness & control flow.

**Hardware:** CPU.

## Lesson sequence

### 04.01 Linear algebra and loss intuition

Status: planned brief.

**Learn and build:** Connect a matrix-vector product to predictions and a scalar regression loss.

**Evidence:** A reproducible experiment for “Linear algebra and loss intuition”: code, environment, observed output, and an explanation of one deliberate change.

**Checkpoint:** Explain your result for “Linear algebra and loss intuition”, identify one failure case, and show how you verified the fix.
