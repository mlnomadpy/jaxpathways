# Phase 12: Reinforcement learning

Specializations.

**Prerequisites:** 05: Neural network training.

**Hardware:** CPU for small environments; accelerator for batched rollouts.

## Lesson sequence

### 12.01 Write a functional environment

Status: planned brief.

**Learn and build:** Express environment transitions and resets as explicit functions.

**Evidence:** A reproducible experiment for “Write a functional environment”: code, environment, observed output, and an explanation of one deliberate change.

**Checkpoint:** Explain your result for “Write a functional environment”, identify one failure case, and show how you verified the fix.
