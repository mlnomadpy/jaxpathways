# Phase 00: Setup & first steps

Start here.

**Prerequisites:** Basic Python; no previous JAX experience.

**Hardware:** CPU; TPU setup is an optional bridge.

## Lesson sequence

### 00.01 Set up your learning workspace

Status: planned brief.

**Learn and build:** Create an isolated Python environment and record the interpreter and JAX version.

**Evidence:** A reproducible experiment for “Set up your learning workspace”: code, environment, observed output, and an explanation of one deliberate change.

**Checkpoint:** Explain your result for “Set up your learning workspace”, identify one failure case, and show how you verified the fix.

### 00.02 Meet your arrays and devices

Status: planned brief.

**Learn and build:** Create an array, inspect its dtype and device, and explain the result.

**Evidence:** A reproducible experiment for “Meet your arrays and devices”: code, environment, observed output, and an explanation of one deliberate change.

**Checkpoint:** Explain your result for “Meet your arrays and devices”, identify one failure case, and show how you verified the fix.

### 00.03 Move your experiment to a TPU

Status: planned brief.

**Learn and build:** Run a device check on a TPU runtime and distinguish installation from successful execution.

**Evidence:** A reproducible experiment for “Move your experiment to a TPU”: code, environment, observed output, and an explanation of one deliberate change.

**Checkpoint:** Explain your result for “Move your experiment to a TPU”, identify one failure case, and show how you verified the fix.
