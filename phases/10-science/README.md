# Phase 10: Scientific computing

Specializations.

**Prerequisites:** 04: Math & optimization.

**Hardware:** CPU first; TPU for scaled simulation.

## Lesson sequence

### 10.01 A functional physical simulation

Status: planned brief.

**Learn and build:** Build a small dynamical simulation with explicit state.

**Evidence:** A reproducible experiment for “A functional physical simulation”: code, environment, observed output, and an explanation of one deliberate change.

**Checkpoint:** Explain your result for “A functional physical simulation”, identify one failure case, and show how you verified the fix.

### 10.02 Vectorize trajectories and scan time

Status: planned brief.

Status: planned brief.

Status: planned brief.
