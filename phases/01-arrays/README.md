# Phase 01: Arrays & pure functions

Shared foundations.

**Prerequisites:** 00: Setup & first steps.

**Hardware:** CPU.

## Lesson sequence

### 01.01 From NumPy to jax.numpy

Status: planned brief.

**Learn and build:** Port a small NumPy computation and compare shapes and values.

**Evidence:** A reproducible experiment for “From NumPy to jax.numpy”: code, environment, observed output, and an explanation of one deliberate change.

**Checkpoint:** Explain your result for “From NumPy to jax.numpy”, identify one failure case, and show how you verified the fix.

### 01.02 Shapes, broadcasting, and dtypes

Status: planned brief.

**Learn and build:** Predict a broadcast result and catch a deliberately incompatible shape.

**Evidence:** A reproducible experiment for “Shapes, broadcasting, and dtypes”: code, environment, observed output, and an explanation of one deliberate change.

**Checkpoint:** Explain your result for “Shapes, broadcasting, and dtypes”, identify one failure case, and show how you verified the fix.

### 01.03 Pure functions and explicit inputs

Status: planned brief.

**Learn and build:** Remove hidden state from a function without changing its result.

**Evidence:** A reproducible experiment for “Pure functions and explicit inputs”: code, environment, observed output, and an explanation of one deliberate change.

**Checkpoint:** Explain your result for “Pure functions and explicit inputs”, identify one failure case, and show how you verified the fix.

### 01.04 Immutable updates and indexing

Status: planned brief.

**Learn and build:** Express an array update with .at and verify the original array remains unchanged.

**Evidence:** A reproducible experiment for “Immutable updates and indexing”: code, environment, observed output, and an explanation of one deliberate change.

**Checkpoint:** Explain your result for “Immutable updates and indexing”, identify one failure case, and show how you verified the fix.
