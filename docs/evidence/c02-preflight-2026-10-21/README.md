The six-branch training record verifies the actual checkpoint identities, complete

The initial live-service probe opened an actual loopback listener, verified
health, a valid two-token generation and rejection of a boolean token budget,

records the exact sources tested; its observed failure remains a repair finding,
not a service qualification. The earlier source snapshot was not retained, so
the source hashes and observations are historical evidence and do not claim a
complete reproducible archive of that earlier service. Future service acceptance

generation and partial-header-isolation probe. Four real loopback tests passed

establish a hard interruption deadline inside native JAX calls.

seconds, kept an incomplete request body open for about 0.86 seconds by sending
small increments. No response or EOF arrived before the probe timeout. The
source starts its deadline timer after the body has been read. This finding
reopens whole-request lifetime acceptance; the four passing tests remain valid
within their narrower scopes. The source snapshot for that repaired version is

weights or tokenizer vocabulary are included here. The owned test listeners were
