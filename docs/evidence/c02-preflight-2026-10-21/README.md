# C02 checkpoint preflight review

These records describe focused internal CPU probes of the developing causal
project. They do not establish an accepted full pilot or model quality.

The initial counterexamples were accepted by the earlier loader. After Luna's
repairs, the valid current fixture loads and all five altered state cases are
rejected: integer first moments despite rewritten local type metadata, negative
second moments, a negative epoch, a clock beyond the frozen horizon, and an
incorrect consumed-sample boundary at the current optimizer step. The retest
records the exact source hashes. Each altered archive was rebuilt with internally
consistent bytes; a ZIP checksum alone could not detect these semantic errors.

The initial record lacks a source snapshot binding and is retained as a finding
that prompted repair. The source-bound retest has the stronger, limited scope of
a valid-control and rejection check on those five cases. Full lineage, fresh
process recovery for every branch, immutable data enforcement, adapter-scale
oracles, actual held-out evaluation and the final current-source run have
separate gates. Do not infer those results from this record.
