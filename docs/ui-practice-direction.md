# Practice-first course interface

Keep paper #ffffff, mist #f5f7fb, ink #18243b, slate #53627a, cobalt #3356c6 and forest #236b59. Avenir/system sans carries navigation, Georgia carries explanations, monospace carries executable code.

The learning catalog opens with material learners can use today. An explicit roadmap control reveals unwritten topics; route and search filters remain combined. Hardware choices explain CPU, virtual CPU device experiments and accelerator validation without equating logical host devices with TPU simulation. Career routes remain visible.

Reader flow: context and prerequisites → choose Python/notebook → explanation → numbered incremental build → run and inspect → predict/experiment → independent practice → checkpoint/evidence. An assembled program is a disclosure when incremental code already exists. Every executable snippet gets its own copy control and accessible result message. Formula/data-flow diagrams stay separate from executable code.

Review: reject another decorative hero or more statistics. The useful visual change is clear executable-code framing and explicit availability, with compact touch controls and no horizontal page overflow. Logical virtual devices demonstrate partitioning semantics, never accelerator speed or topology.
