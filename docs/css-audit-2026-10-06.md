# CSS audit and repairs — 2026-10-06

The audit used the rendered Astro app, computed styles, source inspection, expanded controls, and responsive layout measurements. The existing purple learning-map identity is retained. Changes consolidate ownership rather than adding a final override stylesheet.

## Findings repaired

| Finding                                                                                                 | Repair                                                                                                                                               |
| ------------------------------------------------------------------------------------------------------- | ---------------------------------------------------------------------------------------------------------------------------------------------------- |
| Notebook/planner radios inherit text-field widths and planner label grid layouts                        | Text inputs and radio inputs have separate rules. Choice controls own their labels and 18px radios.                                                  |
| Planner mixes block, flex and grid layouts across multiple generations                                  | One responsive grid, with aligned controls, wrapped choices, separate actions and two-column mobile metrics.                                         |
| Shared header inherits conflicting global header/nav rules                                              | Header owns desktop, tablet, narrow mobile, current-page and menu states, including the GitHub child link. No-JavaScript navigation remains visible. |
| Nested course disclosures inherit the outer phase-card summary layout                                   | Course styling uses direct-child summaries. Nested hardware details have their own density.                                                          |
| Course timeline markers are clipped                                                                     | Phase cards allow markers outside the card; headings, counts and toggles use explicit grid tracks.                                                   |
| Course styles hide useful workflow instructions                                                         | Removed the positional paragraph-hiding rule. Restored the instructions alongside the workflow link.                                                 |
| Lesson titles, numbers and runtime captions compete for space                                           | Separate title markup and a small label grid; runtime metadata aligns beneath the title.                                                             |
| Project stage ordinals touch headings and counters include nested list items                            | Direct-child counters, explicit heading gap, and no misleading ordered-list indentation.                                                             |
| Assessment code uses pale text on a pale background                                                     | Code panels pair foreground/background tokens. Measured preformatted text contrast is at least 12.65:1.                                              |
| Resources/project/guide pages import the entire lesson reader for syntax colors                         | Shared code-panel and syntax styles; removed reader imports from those pages. The lesson reader no longer imports project styles.                    |
| Offline reader images exceed the viewport                                                               | Responsive images, box sizing, sensible figure margins and narrow-screen typography.                                                                 |
| Long lesson process diagrams push the document over 1000px wide                                         | Equations own local horizontal scrolling and a readable monospace layout. Long ordinary prose fragments can wrap.                                    |
| Visually hidden MathML contributes to document width                                                    | Hidden MathML containers contain their overflow while retaining accessible mathematical content.                                                     |
| Mathematical quiz answers become separate flex items and fieldsets retain their intrinsic minimum width | Each answer has one text wrapper; fieldsets/text wrappers can shrink. Long formulas scroll within the answer.                                        |
| Retired homepage styles remain in every page's base bundle                                              | Removed seven obsolete feature sheets. Base CSS imports shared modules only.                                                                         |
| Notebook and course styles depend on unrelated feature sheets                                           | Notebook and course own their styles. Removed misplaced notebook/course rules from reader and pathway sheets.                                        |

## Style ownership

- `src/styles/tokens.css`: palette, typography, focus, code surfaces and reading measure.
- `src/styles/shared/`: reset, typography, page rhythm, controls, disclosures, code panels, choices and accessibility defaults.
- `SiteHeader.astro` and `SiteFooter.astro`: their own navigation and responsive chrome.
- `features/catalog.css`, `workspace.css`, `project.css`: consolidated feature layouts.
- The current homepage continues to use its own existing `home/` styles.

Three architecture regression tests verify that shared composition does not import page features, page templates do not import the lesson reader for shared primitives, CSS imports resolve, and feature sheets do not use bare document/field selectors.

## Verification

- `npm run check`: passed. Astro has zero errors/warnings; TypeScript, ESLint, Prettier, curriculum validation, all **83 tests**, distribution fidelity and root site/SEO checks pass.
- `npm run check:deployment`: passed for `/jaxpathways/`, including eight browser-migration DOM tests. The script restores the root preview build.
- `git diff --check`: passed.
- **102 layout measurements:** 17 page types at 320, 390, 760, 768, 1024 and 1440px. No document overflow; enhanced radios measure 18px.
- **194 lesson measurements:** all 97 permanent lessons at 320 and 1440px. No document overflow.
- Computed foreground/background contrast checked for preformatted panels across both matrices. Transparent preformatted elements are excluded from this contrast calculation.
- Expanded notebook associations, planner schedule generation, nested course hardware details, project OS choices, mobile menu expansion, and Escape/focus restoration checked in the browser.

The measurements use the Codex browser on macOS. This is not a formal screen-reader, print-pagination, or physical-device certification. The changes are local; publication remains a separate action. Existing published UI issues should remain open until their published acceptance checks pass.
