# Frontend direction

## Plan

Audience: learners moving from basic Python into JAX and accelerator systems. Primary job: start a useful lesson or choose a work route, then build and keep evidence.

Tokens: mist #f5f7fb (page), paper #ffffff (reading surface), ink #18243b (text), slate #53627a (secondary text), cobalt #3356c6 (links/actions), forest #236b59 (available content). Borders #d9e1ee carry grouping; no decorative background gradients.

Type: Avenir Next with system sans fallbacks for interface and headings; Georgia for sustained lesson explanations; system mono only for code and numerical shape labels. Sentence case. Comfortable reading column around 65 characters.

Layout:

```
Course   Career routes   My learning notebook
[First array → working system] [A transformation you can inspect]
[Start here] [Find your route]
[Training] [Inference] [Performance / operations] [Research]
[Career chooser → milestones and evidence]
[Real foundation project preview]
[Search + route filter → ordered course phases]
```

Reader: phase context | explanation/build/practice | section outline. Small screens: disclosures above the article. One checkpoint and one evidence action; downloads stay secondary to the lesson.

## Review against the brief

The previous dark, monospaced page gives prose, labels and code too similar a texture. The reference is compelling because it explains a mechanism and supplies a useful next action. Preserve that pattern instead of imitating its typography everywhere. Rejected the default decorative hero illustration in favor of a selectable, honestly labeled code example. Keep career routes visible; show what each domain produces. Use numbering only for real course sequence and milestones. Availability labels must describe real source status.

No curriculum schema migration in this visual pass. Preserve shared lesson IDs, saved learner state, career plans and authored/planned distinctions.
