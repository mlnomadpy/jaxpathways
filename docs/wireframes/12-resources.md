# 12 — Resources and offline reader

Routes: `developer.html`, `downloads/jax-foundations.html`. Goal: find a useful artifact by intent, not configure a search.

## Resource hub — desktop

```text

(section links, all sections stay present)
```

Offer guides before unexplained install commands. The current tutor tools and prerequisites remain available; their setup is user initiated, never automatic. Local tutor state and browser-local state do not sync automatically.

## Offline HTML reader

```text
JAX Pathways — course reader
Available drafts · build context from artifact metadata
[Print / save PDF]                   [Back to resources]
> Contents
  Phase headings with lesson links

FULL READING DOCUMENT
Lesson titles, prose, code, practice, references
```

Printing hides UI controls and preserves meaningful code wrapping. No selected-path filter or dependency on saved browser progress. EPUB is a downloaded artifact, not a website screen. Resource filename legacy explanations stay in details rather than competing with download actions.

## Mobile and states

Stack cards and section links; allow links to wrap into multiple lines rather than making a horizontal carousel. Commands have contained overflow and a wrap option. Offline reader uses one readable column.

Missing artifact: unavailable notice and guide/source fallback; do not present a working download button. Download success is browser-managed and never counts as practice. No account or accelerator subscription is required for the CPU materials.
