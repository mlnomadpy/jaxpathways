# 16 — Careers

Route: `careers.html`. Goal: discover a role and inspect its learning milestones without hunting through the path browser or expanding a hidden section.

```text
JAX Pathways     Course / Learning paths / Careers / My learning / Resources

Explore JAX careers.
Choose a role to see its skills, learning milestones and portfolio goals.
Available lessons and planned work are distinguished in each route.

[ML & training engineer] [RL engineer] [Inference & deployment engineer]
[Operations engineer] [Accelerator & performance engineer]
[Scientific ML engineer] [Research engineer]

Each card: actual role name, work summary, responsibilities, [Explore this role]
```

All seven cards are visible immediately. There is no role dropdown, search form or collapsed career section. Mobile stacks the cards, with Careers available in the shared Menu. Home includes a direct Careers link in both main navigation and its compact curriculum preview.

A card opens the existing career detail view at `careers.html?role=<canonical-id>`. Inspect skills, prerequisites, portfolio goals, ordered milestones and honest content availability. Start a useful lesson, save/download the existing plan, or copy a career link. “All career routes” returns to the cards and restores focus to the selected role. Browser Back retains the existing behavior. Old `pathways.html?role=...` links remain supported; new shared links use Careers.

Shared navigation, including generated assessment pages, includes Careers. Detailed role content and learner state remain sourced from the existing curriculum and career workflow.
