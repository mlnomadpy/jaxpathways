# 08 — Assessment overview, task, and review

Existing families: foundations and models synthesis assessments. Proposed interactive navigation around their existing authored tasks; no grading service is assumed.

## Overview

```text
Course / Project / Synthesis assessment
Defend your experiment.
Assessment review draft · CPU scope

What this checks
Transfer the project to changed conditions and defend the results.

REQUIRED PREPARATION
[Project]  [Required lessons]  > Environment details

TASKS
1 (authored task title)                 [Open task]
2 (authored task title)                 [Open task]
... all authored tasks

[Start first task]            [Download / open full assessment]
> Reviewer guidance (reveal only when wanted)
```

Use exact task titles and count from the assessment source. Reading position may be saved; does not establish an attempt or pass. No time limit unless actually authored, no certificate progress meter.

## Task — desktop

```text
TASK LIST                TASK PAPER                    KEEP THESE ARTIFACTS
● Current task           Problem and changed inputs    Independent calculation
Other authored tasks     Constraints / tolerances      Implementation
                         Predict before execution      Observed output
                         Run external experiment       Explanation of limitations
                         > Hint, if authored
                         [ ] I attempted this task
                         [Save task work] (optional)
                         [Previous task] [Next task]
```

Show rubric expectations before work, but keep worked answers and reviewer solutions in an explicitly labeled disclosure/link. Derivations and runnable code remain real tasks; multiple choice is not a substitute. Hints appear only where authored. Full document remains readable and printable.

## Review preparation

```text
Prepare your work for review
Task 1    Work saved / no work attached          [Open]
Task 2    Work saved / no work attached          [Open]
...
[Download my review summary]
[Open reviewer guidance]
```

Review summary is a proposed local export containing context and optional learner artifacts. It does not send messages or upload files. Learner arranges review outside the site. Label Self-review or Ready to share only as an organizational state, never Independently reviewed. Existing source review instructions remain accessible.

## Mobile

Overview stacks task rows. Task screen has [Task list] near the title; evidence expectations follow the task prompt; previous/next links sit below content. No wide rubric table or mandatory task select.

## States and checks

No attempted tasks: start first task. Partial work: resume exact task without hiding remaining tasks. Missing project evidence: advisory prerequisite links. No assessment authored for a path: show Planned with available project/lesson alternatives. Self-reports and saved work never trigger a passing result.
