## Parent-site repair and search monitoring

Published this child entry to `https://www.tahabouhsine.com/sitemap-index.xml`:

```xml
<sitemap>
  <loc>https://www.tahabouhsine.com/jaxpathways/sitemap.xml</loc>
</sitemap>
```

The host-root robots.txt already references this sitemap index, so it now exposes the project sitemap through that index. The change was made in the separately managed parent website: [commit f33d145](https://github.com/mlnomadpy/mlnomadpy.github.io/commit/f33d145c14a27d1a5433def4707a53fef13730b2). Its GitHub Pages deployment succeeded and the live XML was checked for all eight previous entries plus JAX Pathways.

Submit the project sitemap in the verified Search Console property. Inspect the new book, a phase, a lesson, a learning path and a career guide after deployment. No Search Console access or search-engine index coverage was available during this audit.

## Verification and limits

- Read actual published lesson metadata, the published v0.7.0 book, the host-root robots.txt and root sitemap index. Inspected the Astro templates that emit JSON-LD into initial HTML. Findings do not assume that a text-fetch tool can see client-injected schema.
- Automated checks cover all canonical sitemap destinations, initial HTML, unique titles, nonempty descriptions, one H1, canonical/OG URLs, noindex exclusions, JSON-LD parsing, author identity, visible/schema breadcrumbs, course catalog entries, phase/lesson relationships, book formats, no orphan pages, and a maximum three-link journey from home to each sitemap destination. Existing checks cover local links, accessibility IDs and permanent lesson content.
- Root and `/jaxpathways` deployment bases are checked separately. Search pages do not depend on client JavaScript to expose their core learning content.
- Book downloads retain offline figures, math and appendices. EPUB validation checks XML, MathML, internal links, archive integrity and added catalog metadata.
- Local schema checks are not a Google Rich Results Test or a schema vocabulary service. No claim is made about rankings, indexing, rich-result eligibility, Core Web Vitals or real-user performance. Do not add fictitious course rosters, instructors, reviews or ratings to seek eligibility.
- This is an English-only resource; alternate-language markup would be misleading. Preview/personal workspace and legacy query entry pages remain noindex.
