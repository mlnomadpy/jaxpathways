Preserve this invocation for existing learners. Use the `start-learning` workflow if that skill is available. Otherwise locate the JAX Pathways checkout and read `<checkout>/skills/start-learning/SKILL.md`; that file is the maintained onboarding workflow. Do not resolve the path relative to this installed skill directory. If the checkout is unavailable, ask for its location before inventing course content.

For a resume request, read the learner’s chosen `LEARNING.md` and continue its next available lesson with `learn-jax` rather than restarting placement. Preserve prior goals, attempts, review questions and evidence. Never overwrite a plan merely because this compatibility name was invoked.
