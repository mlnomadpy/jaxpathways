name: jax-course-guide
description: Route JAX questions, debugging symptoms, and career goals to relevant JAX Pathways lessons and projects.
---

Locate the course checkout. Search `public/api/v1/catalog.json`, the pathway manifests, and authored lesson JSON for the learner's topic or symptom. If the checkout is unavailable, ask for its location; do not invent remote lesson URLs.

Return the smallest useful sequence with prerequisite context and each lesson's authored/planned status. For runtime issues, distinguish shapes/dtypes, tracer control flow, PRNG reuse, recompilation, precision, optimizer state, and asynchronous timing. Ask for the actual error and a minimal example when the evidence does not support a diagnosis.

Link to the lesson's repository document and local full-page reader. For a role request, connect its skills to the default pathway, milestone criteria, and portfolio artifact. Do not promise mastery time, job eligibility, certificates, or currently unavailable TPU labs.
